Ajouter / éditer les métadonnées

Renseignez un champ pour l'ajouter, videz-le pour le retirer. L'original n'est jamais modifié.

« Enregistrer » crée une copie *_edited (l'original reste intact). « Nettoyer » supprime toutes les métadonnées (*_clean).

Une copie nettoyée *_clean est enregistrée à côté de l'original (les fichiers glissés vont dans Téléchargements). L'original n'est jamais modifié. Le ré-encodage JPEG/WebP peut légèrement recompresser l'image.
